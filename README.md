Cisco VLAN Network Segmentation

Project Overview

This project uses Cisco Packet Tracer to design a segmented network for four departments. Each department operates on a separate VLAN to support logical separation and controlled communication.

Network Components

1 Cisco 2911 router

2 Cisco 2960 switches

8 PCs

4 departmental VLANs

Technologies and Configuration

VLAN creation and switch port assignment

Trunk links using 802.1Q

Router-on-a-stick inter-VLAN routing

Access Control Lists (ACLs) to restrict inter-VLAN traffic

Project Deliverables

Packet Tracer file: Network simulation and device configuration

IP addressing table: Device addressing and gateway information

Topology diagram: Visual representation of the network design

Verification

Connectivity tests should confirm communication within the intended VLANs and verify that inter-VLAN traffic is restricted according to the ACL rules.
